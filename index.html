Universal POS (UPOS) — 17 tags

Try the mini rule-based tagger. It uses (1) a lexicon lookup, (2) suffix/capitalization guesses for unknown words, then (3) contextual transformation rules.
Rules used
  1. Lexicon: first listed tag is the initial tag.
  2. Unknown: digits→CD; capitalized mid-sentence→NNP; -ly→RB; -ing→VBG; -ed→VBD; -ous/-ful/-able/-ive→JJ; -s→NNS; else NN.
  3. R1: VB/VBP after DT or PRP$ → NN.
  4. R2: NN after TO → VB.
  5. R3: NN/VBP after MD → VB.
  6. R4: VBD after was/were/is/are/has/have/had/be → VBN.

Try: “She can swim”, “I want to play”, “The book was written”, “They have eaten”.
